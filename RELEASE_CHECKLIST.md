## Сеть и безопасность

- [x] Контролируемые HTTP-тесты: 429/Retry-After, 5xx, GraphQL errors при 200, некорректный JSON, транспортная ошибка, общий таймаут и очередь.
- [x] Устаревшие ответы игнорируются; зависший IPC заканчивается ошибкой; запросы другого каталога не отправляются.
- [x] Полностью локальные сценарии проверены с недоступным proxy и `navigator.onLine=false`; физическое отключение адаптера не выполнялось.
- [x] Живой Shikimori `.io`: сезон, популярное, жанры, поиск Death Note и подробная карточка с русским названием/37 сериями подтверждены в release и установленном приложении. Недоступный `.one` заменён рабочим адресом того же каталога.
- [ ] Повторное подтверждение актуальных требований Shikimori к User-Agent и квотам: документация недоступна. Приложение использует `AnimDesk/1.0`, 1 запрос/сек и 45/мин.
- [x] CSP включена, нативный заголовок, точечные SQL/path permissions, без shell/произвольного HTTP и небезопасного HTML.
- [x] Проверка изображений, размеров, MIME, путей, ссылок/reparse points и ограничений JSON; параметризованные записи и атомарный импорт.
