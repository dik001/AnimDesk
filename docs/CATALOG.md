# Каталог AnimDesk

Единственный онлайн-источник — Shikimori GraphQL: `POST https://shikimori.io/api/graphql`. User-Agent `AnimDesk/1.0`. Другие API не вызываются. Старые provider ID остаются в локальной модели и JSON для совместимости.

## Слои

- `types.ts`: нормализованная карточка, ошибки, фильтры и сезон.
- `providers.ts`: Shikimori, защитная проверка JSON и словарь жанров.
- `mappers.ts`: нормализация Shikimori и совместимость прежних метаданных; описания выводятся plain text.
- `service.ts`: кеш до 100 результатов на 5 минут, поиск, детали, локальная карточка при сетевой ошибке. Сеть не заменяет ошибку пустым массивом.
- `storage.ts`: сохранение метаданных в существующую SQLite. Списки сами по себе не добавляются в библиотеку.
- Rust `catalog.rs`: фиксированные операции и адрес, запрет произвольных URL/GraphQL со стороны JS, HTTPS, запрет редиректов и лимит ответа 4 MiB.

Лимиты: минимум секунда между запросами, максимум 45 за скользящие 60 секунд. Две попытки при транспортной ошибке или 5xx. HTTP 429 учитывает число секунд или HTTP-дату `Retry-After`; длинный cooldown возвращает явную ошибку без новых запросов. Таймаут подключения 3 секунды, HTTP 5 секунд, вся Rust-операция 12 секунд, IPC 14 секунд. UI-loader ограничен 35 секундами, включая локальную БД и словари. AbortSignal подавляет устаревшие ответы и последующую запись; уже отправленный HTTP может завершиться.

## Идентичность и офлайн

Shikimori ID не приравнивается к MAL ID. Сопоставление только по исходной паре или подтверждённым внешним ID. Конфликт не объединяет записи. Похожие названия не объединяют сезоны. Старые записи другого provider обновляются только при известном Shikimori ID; иначе доступны локально.

Сохранённые детали открываются до ответа сети. При сбое остаются локальные данные и предупреждение. Библиотека, прогресс, заметки, профиль, статистика и перенос работают через SQLite. Кеш обложек читает проверенные файлы; недоступный или повреждённый файл заменяется заглушкой.

## Проверка доступности — 24 октября 2026

При сравнении реальных POST с User-Agent `AnimDesk/1.0` `.one` не ответил за 12 секунд, а `.io` вернул HTTP 200 с Death Note (ID 1535, русское название и 37 серий) за 0,73 секунды. Endpoint исправлен на `.io`, без автоматических редиректов и второго источника. Опубликованные требования API к квотам повторно не подтверждены из-за недоступности страницы документации; локальные ограничения сохранены консервативными.

Схема запросов: [официальные исходники Shikimori](https://github.com/shikimori/shikimori/tree/master/app/graphql). Пользовательские данные туда не отправляются.

После пересборки нативная release и установленная копия подтвердили живые сезон/популярное, словарь жанров, поиск Death Note и подробную карточку «Тетрадь смерти», 37 серий. Ответы API не подменялись.
