# Совместимость хранения

Официальное имя продукта — AnimDesk. Технические ключи хранения остаются стабильными:

- Tauri identifier: `app.anidesk.desktop`.
- SQLite: `sqlite:anidesk.db`, файл `%APPDATA%\app.anidesk.desktop\anidesk.db`.
- Прежний относительный кеш `cache/covers`, аватар `avatars` и защитные экспорты `backups` остаются в том же каталоге.

Эти идентификаторы нужны для открытия существующих данных. Каталог и файл не переименовываются; копирование, миграция путей и создание новой базы при обновлении не требуются. Профиль, настройки, библиотека, статусы, прогресс и оценки остаются в той же SQLite. Полный технический путь виден в настройках для резервного копирования.

Новый экспорт использует `format: "animdesk-library"` и `schemaVersion: 1`. Импорт принимает также прежний `format: "anidesk-library"` только с `schemaVersion: 1`. Оба формата проходят одинаковую полную проверку данных до записи. Повторный экспорт и защитная копия всегда используют новый формат. Правила транзакций, сопоставления по достоверным ID и отката не меняются.
